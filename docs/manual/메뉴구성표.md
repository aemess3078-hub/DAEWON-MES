## 3. 접근 불가·숨김 [UI+SRC]
| 구분 | 항목 | 결과 |
|---|---|---|
| 일반 사용자에게 404 | 대시보드 /app/mes/dashboard, 품목단가 /app/mes/item-prices, 제조번호 추적성 /app/mes/manufacturing-traceability | 대원정밀 범위 정책(허용 목록 밖). 개발자 로그인 `test` 전용 |
| 개발자 전용(메뉴 숨김) | 설비연동(Edge Gateway, 설비 연결 설정, 태그 사전), 시스템(기능 관리), 코드관리 | `developerOnly` / `DAEWON_DEV_ONLY_ROUTES` |
| 메뉴만 숨김(`DAEWON_HIDDEN_NAV`) | 프로젝트 오더 등 4종, 반품관리, 설비별생산현황, 품질현황, 공정검사, SPC, 원인분석·조치·재발방지, 첨부파일관리, 감사로그, 금형, 비가동사유, 백업관리, KPI, 생산일보·품질·설비 리포트, LMS 부가 메뉴, 요청사항 | 총 40여 개. 대부분 허용 목록 밖이라 일반 사용자는 URL 직접 접근도 404. 허용 목록에는 있으나 메뉴가 숨겨진 것: 첨부파일관리·감사로그 |
| 역할 제한 | 사용자관리, 번호 규칙(minRole ADMIN) | 오너로는 표시. 매니저·작업자·조회자로는 확인하지 못함 [미확인] |
