데이터는 2026-11-11 앱 서버 액션으로 생성되어 있고, 이번 단계에서 변경하지 않았다. 수량 정합성(28개 항목)은 `prisma/seed-manual-scenarios.ts --verify`로 재확인(통과). 실제 화면에서 보았는지는 **[UI]**, DB/소스로만 확인은 **[DB]/[SRC]**.

## 업무 흐름과 화면 (공통)
수주등록(03-01) → 생산계획(06-01) → MRP(04-06) → 자재발주(04-01) → 자재입고(04-02) → 자재출고(04-03) → 작업지시(06-02) → POP(07-02) → 작업일지/실적(06-04) → 초중종검사(09-02)·최종검사(09-03) → 완제품입고(06-05) → 납품정보등록/출하(03-03) → LOT 이력추적(11-02)

선행 조건 [SRC]: 자재출고(원본 WIP 생성) 후에야 POP 작업 시작 가능 · 앞 공정 완료 후 다음 공정 시작 · 마지막 공정에 검사표준이 있으면 최종검사 합격 후 완제품입고·출하 가능(이전 작업에서 확인).
