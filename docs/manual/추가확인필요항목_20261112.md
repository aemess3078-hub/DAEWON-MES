# 추가 확인 필요 항목 목록

기준: `대원정밀_MES_사용자매뉴얼.html`(2026-11-12 수정 반영본)에 "추가 확인 필요"·"확인하지 못했습니다"·"확인 중"으로 표시된 항목을 모두 추출했다(페이지별 todo 40건 → 같은 사유는 묶어 아래 표로 정리, 전체 목록 12행에 "운영 MES 반영 여부" 1건 추가).
**이번 단계에서는 등록·저장·확정 등 업무를 실행하지 않았고, 확인되지 않은 기능은 그대로 보류했다.**

"DB 변경 필요"는 검증하려면 데이터가 생성·변경되는지를 뜻한다. 변경이 필요한 항목은 **운영 DB·매뉴얼 DB를 직접 쓰지 말고 격리 DB(예: WSL 테스트 PG 복원본)에서** 검증한다.
